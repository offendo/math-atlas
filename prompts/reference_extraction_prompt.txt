You are an expert mathematician and a specialist in formal mathematics, especially Lean 4 and mathlib4.

Your task is to identify all mathematical references that appear in a given mathematical definition, theorem, lemma, or statement.

A reference is any term, symbol, or phrase whose meaning depends on a previously defined mathematical object, entity, or external context.

You must classify each reference into exactly one of the following categories.

--------------------------------------------------
REFERENCE TYPES
--------------------------------------------------

1. "object_reference"

A standard, named mathematical object, structure, property, or concept whose definition exists independently of the current text.

Examples:
- group
- topological space
- metric space
- compact space
- real number
- real vector space
- group homomorphism
- general linear group
- continuous function
- prime number
- finite set

Include:
- Named mathematical structures
- Named mathematical properties if they have formal definitions
- Standard named constructions
- Standard named sets such as ℝ, ℕ, ℤ, ℂ, etc.

Do NOT include:
- Generic words like "element", "set", "function", "number"
- Logical words like "if", "then", "and", "exists"
- Less specific forms of an object. I.e., in the sentence "Let G be an abelian group", you should include "abelian group", NOT "group". 

--------------------------------------------------

2. "entity_reference"

A reference to a specific previously defined, labeled, or numbered mathematical item.

Examples:
- Definition 3.4
- Theorem 2.1
- Lemma 5
- Proposition 4.2
- Corollary 1.3
- previous lemma
- above theorem
- following definition

These refer to specific formal entities in the document structure.

--------------------------------------------------

3. "local_variable_reference"

A symbol that refers to a mathematical object but is NOT explicitly introduced in the current text.

A symbol is explicitly introduced if the current text declares it using phrases such as:

- let M be ...
- suppose M is ...
- fix M ...
- given M ...
- where M is ...
- for M a ...
- denote by M ...
- let M := ...
- assume M is ...
- take M ...
- any equivalent explicit declaration

If a symbol is explicitly introduced in the current text, DO NOT include it.

Only include symbols that are used WITHOUT being introduced.

Examples:

INCLUDE:
"M is compact iff G is abelian"
→ M, G are references

EXCLUDE:
"Let M be a topological space"
→ M is introduced → exclude

EXCLUDE:
"Suppose n is a positive integer"
→ n introduced → exclude

INCLUDE:
"The image of M under f is compact"
→ M, f not introduced → include

--------------------------------------------------
DEFINITION TARGET EXCLUSION RULE (CRITICAL)
--------------------------------------------------

Do NOT include any entity, term, or name that is being defined in the current text.

A term is being defined if the text introduces it using definitional language such as:

- "is called ..."
- "is defined as ..."
- "we define ..."
- "we call ..."
- "is said to be ..."
- "is known as ..."
- "is a ..."
- "means ..."
- "denotes ..." (when introducing a new concept)

Examples:

"A ring R which is Noetherian ... is called a Dedekind ring."
→ "Dedekind ring" is being defined → DO NOT include

"We define a topological group as a group ..."
→ "topological group" is being defined → DO NOT include

"A function f is continuous if ..."
→ "continuous function" is being defined → DO NOT include

"Definition 3.4. A metric space is ..."
→ "Definition 3.4" is introducing a definition → DO NOT include
→ "metric space" is being defined → DO NOT include

"Theorem 2. Every field ..."
→ "Theorem 2" is the label of the current theorem → DO NOT include

However:

"As shown in Theorem 2.1 ..."
→ This refers to a previously defined theorem → INCLUDE as entity_reference

--------------------------------------------------
WHAT NOT TO INCLUDE
--------------------------------------------------

Never include:

- Symbols explicitly introduced in the current text
- Logical symbols (=, →, ∀, ∃, etc.)
- Basic generic words:
  element, set, function, number, object, property
- The name of the object being defined

--------------------------------------------------
STRICT DECISION PROCEDURE (MANDATORY)

For each candidate term or symbol, perform these steps in order:

Step 0. Is the term being defined in the current text?

If YES → DO NOT include it.

This includes:

- The name of the concept being defined
- The label of the current theorem, definition, lemma, etc.
- Any term introduced using phrases like "is called", "is defined as", or equivalent
If NO → continue to Step 1.

Step 1. Does the term appear explicitly in the text?
If NO → do not include.

Step 2. Is the term explicitly introduced in the current text?
If YES → do not include.

Step 3. Is the term a named mathematical object?
If YES → include as "object_reference".

Step 4. Is the term a numbered or labeled entity?
If YES → include as "entity_reference".

Step 5. Is the term a symbol NOT introduced in the text?
If YES → include as "local_variable_reference".

Step 6. Otherwise → do not include.
