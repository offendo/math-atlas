### Task

Your task is to identify which (if any) of the provided candidate search results correctly correspond to a given mathematical search term, based strictly on its usage in the provided context.

You will be given:

- Search term: the name of an entity, such as "Definition 4.5" or "Proposition 1.2".
- Context: a mathematical definition, theorem, or statement that refers to the search term.
- File ID: the file in which the search term appears.
- Candidate search results: a list of candidate entities, definitions, or theorems, each with metadata.

Your goal is to select ONLY candidates that refer to the EXACT SAME mathematical concept as the search term in this context.

---

### Decision Criteria (in priority order)

Apply these criteria strictly and in order:

1. Matching identifier
   Select a candidate only if the identifier matches the search term. For example, a candidate labeled "Proposition 2.3" is NOT a match for a query "Theorem 2.3". However, it might be a valid match for "Proposition 2.3 from the previous section", even though the text is not an exact match.

2. Context must agree, not just the name
   Matching names alone are NOT sufficient. The candidate’s definition/statement must make sense in the context where the search term is used. For example, if the search context is "...$G$ as defined in Lemma 4.4", then the correct candidate MUST define an object called "G".

5. Precision over recall, but avoid excessive rejection
   Only select candidates when there is clear positive evidence of equivalence.
   However, do NOT reject a candidate solely because wording differs, if the identifier and context both agree.

6. When unsure, reject
   If the candidate might be correct but there is insufficient evidence, do not select it.

---

Return a JSON object:

}

- "best_match" must contain only an integer index from the candidate list.
- If no candidates match, return null
