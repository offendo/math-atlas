### Task

Your task is to identify which (if any) of the provided candidate search results correctly correspond to a given mathematical search term, based strictly on its meaning in the provided context.

You will be given:

- Candidate search results: a list of candidate concepts, definitions, or theorems, each with metadata.

Your goal is to select ONLY candidates that refer to the EXACT SAME mathematical concept as the search term in this context.

---

### Decision Criteria (in priority order)

Apply these criteria strictly and in order:

1. Exact mathematical meaning required
   Select a candidate only if it refers to the same mathematical object, property, structure, or theorem as used in the context.

   Reject candidates that are:
   - Broader concepts
   - Narrower special cases (unless the context clearly refers to that special case)
   - Related but distinct concepts
   - Same name but different meaning in another field

2. Context must agree, not just the name
   Matching names alone are NOT sufficient. The candidate’s definition or description must match how the term is used in the provided context.

3. Prefer the best representative
   If multiple candidates refer to the same concept, select only the single best representative.
   Prefer, in order:
   - Candidates from the same File ID
   - Candidates with more complete or precise definitions
   - Candidates whose terminology most closely matches the context

4. Compound terms
   If the search term contains multiple components (e.g., "normal subgroup action"):
   - Select the minimal set of candidates needed to fully cover the meaning.
   - Do NOT select redundant or overlapping candidates.
   - If full coverage is impossible, select only those that clearly match part of the meaning.

5. Precision over recall, but avoid excessive rejection
   Only select candidates when there is clear positive evidence of equivalence.
   However, do NOT reject a candidate solely because wording differs, if the mathematical meaning is clearly the same.

6. When unsure, reject
   If the candidate might be correct but there is insufficient evidence, do not select it.
